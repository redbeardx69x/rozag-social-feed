Made for RoZAG

RoZAG Social Hub is a multi-server Discord application for creator-feed automation.

  • Automatic Social Hub setup
  • Slash-command management
  • Creator-to-Discord member linking
  • Private TikTok authorization DMs
  • Per-server feed delivery
  • Creator Watch — follow external YouTube creators without requiring Discord membership
  • Platform roadmap with Coming Soon integrations

Simple administration

Server admins manage the system directly from Discord.

  • /setup_social_hub — create or repair the hub
  • /social add — add a creator and link the owning Discord member
  • /social list — view connected accounts
  • /social remove — remove an account
  • /creator watch — watch external YouTube creators without requiring Discord membership

Authorization note: Twitch and TikTok accounts require the creator to be a Discord member so RoZAG can complete platform authorization.
