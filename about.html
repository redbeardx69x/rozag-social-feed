How it works

Built for community sharing

RoZAG Social Feed is intended to reduce repetitive checking for participating creators and community moderators. The service monitors only the sources and permissions that a creator has intentionally connected.

1. A creator connects an account

When a supported platform requires authorization, the creator signs in through that platform's official authorization flow and grants only the permissions requested by the application.

2. The service checks permitted content

The application retrieves the content information allowed by the platform's API and the creator's authorization. For the initial TikTok integration, the intended use is retrieving a participating creator's permitted public video information.

3. A link is shared with the community

When new content is detected, the service can publish a link and basic identifying information such as the creator name and video title to the configured RoZAG community Discord feed.

4. Duplicate posts are avoided

The service records identifiers for content it has already processed so the same link is not repeatedly posted.

What the service does not do

  • It does not claim to be TikTok, YouTube, Twitch, or Discord.
  • It does not remove watermarks or alter creator content.
  • It does not sell creator data.
  • It does not request permissions that are unnecessary for the intended feature.
  • It does not publish content to a creator's social account as part of the feed feature.
Important: The final production behavior will be limited by the permissions and API access approved by each platform.
